Este repositório contém alguns projetos simples feitos em HTML para praticar estrutura, semântica e estilo básicos.

São páginas que mostram:  
- listas de bandeiras com links;  
- explicação rápida sobre semântica;  
- diferença entre linguagens server e client side;  
- uso básico de metadados;  
- link para vídeo com texto simples.
